## 🎮 Sobre o projeto

Os encanadores mais famosos do Reino dos Cogumelos agora têm site! Este projeto simula a landing page de uma empresa de encanamento temática protagonizada por Mario e Luigi — com copy divertido, identidade visual fiel ao universo do jogo e funcionalidades reais de contato.

Desenvolvido durante os primeiros passos com JavaScript no Front-End, o desafio foi unir criatividade com técnica: responsividade, organização visual, semântica HTML e interações reais com o usuário.

---

## ✦ Funcionalidades

- Layout responsivo para desktop e mobile
- Navegação com seções: Home, Nossos Serviços e Fale Conosco
- Hero section com copy temático e CTA de contato
- Integração direta com WhatsApp para orçamentos
- Botão flutuante de contato rápido
- Player de vídeo incorporado
- Primeiras interações e efeitos com JavaScript
